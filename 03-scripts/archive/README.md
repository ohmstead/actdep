# Archived scripts

Exploratory and superseded analyses kept for provenance. **None of these are
required to reproduce the manuscript**. Their output paths point into
`05-results/archive/`, so running one cannot overwrite a manuscript figure.

| Script | What it was | Why it is here |
|---|---|---|
| `SuppFigure5.R` | Early version of the Figure 6 clock/IEG heatmaps | Superseded by `figures/Figure6A-J.R` |
| `SuppFigure6.R` | Baseline (SE) IEG expression across ZT, per subclass | Not used in the final supplement set |
| `SuppFigure7.R` | Neurogenesis module scores across subclasses/ZT | Superseded by `SuppFigure7_revised.R` |
| `SuppFigure7_revised.R` | Detection of neurogenesis markers along the stage axis | Not used in the final supplement set; outputs in `05-results/archive/neurogenesis_stage_axis/` |
| `SuppFigure_pbComparison.R` | Pseudobulk-method comparison scatterplots | Superseded by the forest plots and RRHO maps (Figure 2—supps 2–5) |
| `Figure5_SuppFig2_voom_ZT_heatmaps.R` | Figure 5B-E ZT heatmaps refit with limma-voom | Not used in the final supplement set; outputs in `05-results/archive/Figure5_SuppFig2_voom_ZT_heatmaps/` |
| `forest_plots_all_subclasses.R` | Forest plots looping every subclass × contrast, one page each | Superseded by `figures/Figure2_SuppFig2.R` (CA1) and `Figure2_SuppFig3.R` (DG), which lay the four contrasts out as a readable 2×2 grid |
